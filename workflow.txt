    Summary
    POST /ingest = scrape URLs, split text, embed chunks, store them
    POST /chat = embed question, retrieve similar chunks, generate answer with Gemini, return answer + sources



Complete Workflow

1. Ingestion Workflow
   ---------------------->

Request:
POST /ingest
Body:
List<String> of URLs

Controller:

-IngestController.ingest(...)

Calls:

-IngestionService.ingestUrls(urls)

IngestionService:

For each URL:

* Detect content type (HTML, PDF, DOCX, TXT, Google Drive PDF)
* Route the URL to the appropriate parser

HTML URLs:
* Fetch content using Jsoup
* Remove unwanted elements (nav, header, footer, script, style, noscript, iframe)
* Extract text from headings and paragraphs
* Extract page title

PDF URLs:
* Download PDF
* Extract text using Apache PDFBox

DOCX URLs:
* Download DOCX file
* Extract text using Apache POI

TXT URLs:
* Download text file
* Read content as UTF-8 text

Google Drive PDF URLs:
* Convert sharing URL into direct download URL
* Download PDF
* Extract text using Apache PDFBox

After content extraction:
* Create a LangChain4j Document
* Attach metadata (source_url, title)
* Split document into chunks using DocumentSplitters.recursive(1000, 200)
* Generate embeddings for each chunk
* Remove existing chunks for the same source URL
* Store chunks, embeddings, and metadata in the database

Response:

Success = X
Failed = Y



    2. Chat workflow  ----------------------->
    Request:

    POST /chat
    Body: { "question": "..." }
    Controller:

    ChatController.chat(...)
    Gets client IP
    Calls RAGService.chat(question)
    Saves user question/answer history via UserDetailsService



    RAGService:
    -Create embedding for the question using EmbeddingService.embed(question)
    -Load all stored DocumentChunk entries from DocumentChunkRepository
    -Compute cosine similarity between question embedding and each chunk embedding
    -Sort and select top k chunks (top 5)



    Context building:
    -Join selected chunk texts into one context string



    Response generation:

    -Call GeminiService.generateResponse(context, question)
    -GeminiService builds a prompt with:
    -system instructions
    -context
    -question
    -Sends it to the configured ChatModel


    Return:
    ChatController returns:
    -answer
    -list of sources with url and chunk text
